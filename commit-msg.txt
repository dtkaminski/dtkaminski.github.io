Say why five font weights stay numeric

Correction to the previous commit, which claimed greta-app.jsx has no numeric font
weight anywhere. Five remain, and they are correct:

  1894  fontWeight={700}                      <text> on a timeline marker
  5444  fontWeight={700}                      <text> on a funnel node
  9298  fontWeight="600"                      <text> recharts bar label
  10828 fontWeight={i===trough.i?700:400}     <text> cash-trough axis labels
  10830 fontWeight="700"                      <text> cash-trough balance

They are SVG presentation attributes, not CSS style properties, and SVG attributes
cannot resolve var() — the same rule that forces chart colours through PAL instead of
var(). Tokenising them would silently drop every one to default weight, and since they
sit in charts nobody reads closely, it would not be obvious.

They were invisible to my scans because JSX spells an attribute fontWeight={700}, while
every pattern I used looked for the style-object form fontWeight: 700. Two different
spellings of the same property, and only one of them can take a token.

So each site now carries a one-line reason. CLAUDE.md bans hardcoded visual values, so
the next person to sweep this file will find these and be right to question them; the
comment is there to stop the answer being a regression.

greta-app.js is byte-identical to the previous commit — JSX comments are compile-time
only — so no rebuild and no cache-bust is included.
