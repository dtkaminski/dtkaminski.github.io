Define --weight-bold and land the type-token sweep

Replaces every hardcoded font size and weight in greta-app.jsx with a design token:
1,051 var(--text-*) references and 418 var(--weight-*). CLAUDE.md has banned hardcoded
px type since the design system landed; this is the file finally complying.

The sweep was written in a previous session and left uncommitted because it could not
ship. It referenced var(--weight-bold) 182 times and no such token existed --
design-tokens.css defined normal/medium/semi and stopped. Shipping it would have
resolved 182 font-weight declarations to nothing, so 182 elements would have silently
dropped to inherited weight. --weight-bold: 700 is added here, continuing the existing
400/500/600 scale.

IT IS NOT A NO-OP RENAME, and the collapse is the point. The file carried nine distinct
numeric weights; there are now four tokens:

  400              -> --weight-normal   38 sites, exact
  450, 500, 550    -> --weight-medium   15 sites
  600, 650         -> --weight-semi    183 sites
  700, 750, 800    -> --weight-bold    182 sites

So 24 places previously set to 800 now render at 700, and the 450/550/650/750 strays
round to the nearest step. An arbitrary nine-step weight scale reached by nudging
individual components is exactly the debt the token system exists to remove, so this is
a deliberate normalisation rather than drift -- but 800 did exist, and if any of those
24 need to stay heavier the answer is a --weight-heavy token, not a number back in the
component.

Font sizes collapse the same way, including quoted values like '12.5px' that were
outside any scale.

Verified as a pure token migration before committing: normalising every weight and size
token on both sides leaves 200 differing lines, all of them whitespace (fontSize:SS
versus fontSize: SS) or quoted-px sizes. No logic, no markup, no copy changed. Every
token the file now references resolves in design-tokens.css. node --check passes and
greta-app.js rebuilds byte-identically from this source.

Recovered from a scratchpad copy. The sweep disappeared from the working tree during
